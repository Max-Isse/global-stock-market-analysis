# Global Stock Market Trend Analysis

## Overview

This project analyzes historical stock data for major technology companies to identify long-term market trends and return patterns.

The goal is to demonstrate financial data research, cleaning, analysis, and visualization using Python.

## Companies Analyzed

- Apple (AAPL)
- Microsoft (MSFT)
- Google (GOOGL)
- Amazon (AMZN)
- Tesla (TSLA)

## Tools Used

Python  
Pandas  
Matplotlib  
Yahoo Finance API  

## Project Workflow

1. Collect historical stock data using yfinance
2. Clean and structure the dataset
3. Calculate daily returns
4. Analyze volatility and trends
5. Visualize stock performance

## Key Findings

- Large technology firms showed strong long-term returns.
- Tesla displayed the highest volatility.
- Microsoft and Apple demonstrated relatively stable growth patterns.

## Repository Structure

data – raw financial datasets  
notebooks – analysis notebooks  
scripts – data collection scripts  
visuals – charts and visual outputs
